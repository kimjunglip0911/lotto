# 추천 번호 20세트가 만들어지는 흐름

> 이 문서는 **개발 내부 로직**이 아니라, 사이트를 사용하는 입장에서  
> **"버튼 한 번 누르면 왜 그 20세트가 나오는가?"** 를 설명합니다.

---

## 2. 20세트는 "이렇게" 만들어집니다

추천 번호 20세트는 **마구잡이 무작위가 아닙니다.**  
**1~45에서 직전 당첨 7개를 뺀 풀**로, 세트를 **두 그룹**으로 나눠 만듭니다.

### 공통 전제

| 항목 | 현재 동작 |
|:---|:---|
| **번호 풀** | 1~45에서 **직전 회차 당첨번호(본번호 6 + 보너스 1)** 를 제외 (중복이면 고유 개수는 7 미만) |
| **통계 표본** | 기준 회차 직전 **약 3년(156회)** |
| **홀짝 비율** | 쓰지 않음 |
| **합계 구간** | 사실상 제한 없음 (전 구간 허용) |
| **번호 사용 횟수 한도** | 원래 “20세트에서 같은 번호 최대 3회” 규칙이 있으나, **지금은 잠시 꺼 둔 상태** |
| **과거 당첨 조합** | 기준 회차 **이전**에 실제로 나온 **본번호 6개**와 같으면 후보에서 뺌 (보너스 제외) |

### 1그룹 — RANK1~10 (번호별 간격 순위)

각 번호가 **과거 최장 공백(최대 간격)에 얼마나 가까운지**를 봅니다.  
출현은 **본번호 6개 + 보너스 1개**를 모두 셉니다(같은 회차에 겹치면 한 번만).

1. 기준 회차 직전까지, 번호마다 과거 간격 중 **최대 간격**을 구합니다.  
2. **현재 간격**(마지막 출현 후 몇 회가 지났는지)을 구합니다.  
3. **현재 > 최대**인 번호(기록 갱신 중)를 먼저 두고, 초과폭(`현재−최대`)이 클수록 위입니다.  
4. 그다음 `|현재 − 최대|` 이 **작을수록** 순위가 높습니다.  
5. 최대 간격을 못 만드는 번호(출현 0~1회)는 **맨 아래**입니다.  
6. 그 순위로 1등~45등까지 매긴 뒤, 세트마다 **6칸**씩 잘라 씁니다.

| 세트 | 쓰는 간격 순위 칸 |
|:---|:---|
| RANK1 | 1~6등 |
| RANK2 | 7~12등 |
| … | … |
| RANK10 | 55~60등 (45를 넘는 칸은 남는 번호로 보완) |

→ “최대 공백을 넘긴/가까운 번호”부터 “아직 여유가 있는 번호”까지를 **10세트에 나눠** 보여 줍니다.

### 2그룹 — RANK11~20 (자리별 번호대 순위)

과거 당첨번호 6자리를 **번호대(1~45, 1개 단위)** 로 보고,  
최근 3년 동안 **자리마다 자주 나온 번호대**를 순위로 매깁니다.

| 세트 | 자리대 시작 순위 |
|:---|:---|
| RANK11 | 구간 1등 band |
| RANK12 | 구간 2등 band |
| … | … |
| RANK20 | 구간 10등 band |

- 1번 자리(1구)부터 6번 자리(6구)까지 **순서대로** 번호를 고릅니다.  
- 목표 번호대가 이미 쓰였거나 후보가 없으면, **다음 등수 번호대**로 넘어갑니다(ladder).  
- 조합 분석 화면(`/combination`)과 **같은 3년 표본·자리대 규칙**을 씁니다.

### 슬롯을 채울 때 추가로 규칙

- 이미 만든 세트와 **6개 번호가 완전히 같으면** 쓰지 않습니다.  
- 겹치면 자리 하나를 골라 **번호 1개만** 바꿉니다(전체를 처음부터 다시 뽑지 않음).  
- 뒤쪽 슬롯(예: RANK19~20)이 안 만들어지면, **직전 세트를 되돌리고** 다른 조합으로 다시 시도합니다.  
- 그래도 부족하면 **가능한 만큼만** 보여 주고, 목표 20개보다 적다는 안내를 붙입니다.

## 3. 자주 묻는 점

- **왜 20세트인가요?**  
  앞의 10세트는 **간격(타이밍)** 관점, 뒤의 10세트는 **자리대(배치)** 관점입니다.  
  두 축을 나란히 보면 한눈에 비교하기 좋은 분량입니다.

- **회차를 바꾸면 세트도 바뀌나요?**  
  네. 회차마다 **그 시점까지의 당첨 이력**으로 간격·자리대를 다시 계산하기 때문에,  
  다른 회차를 고르면 20세트가 달라집니다.

- **무작위로 나오는 건가요?**  
  아닙니다. **간격 순위 → 자리대 순위 → 과거 당첨·중복 제외** 순으로 정해진 규칙입니다.  
  같은 회차·같은 이력에서는 **항상 같은 20세트**가 나옵니다(재현 가능).

- **직전 당첨번호는 왜 빼나요?**  
  바로 전에 나온 번호(보너스 포함)를 이번 추천에서 빼 두면,  
  “직전 번호를 그대로 다시 고르는” 경우를 줄일 수 있습니다.  
  기준 회차보다 앞선 당첨이 없으면(예: 1회차) 제외 없이 1~45를 씁니다.

- **예전에 말하던 “채택 풀에서 번호 빼기”는 없나요?**  
  편차·누적 극값·연속 출현으로 후보를 줄이는 단계는 **쓰지 않습니다**.  
  지금 풀에서 빼는 것은 **직전 회차 당첨 7개**뿐입니다.

- **홀짝·합계 조건은요?**  
  현재는 **홀짝 비율을 맞추지 않고**, 합계도 **거의 제한하지 않습니다**.

- **100% 당첨 보장인가요?**  
  아닙니다. 로또는 본질적으로 확률 게임이며, 이 사이트는  
  **"과거 통계상 간격·자리대 패턴"** 을 정리해 보여 줄 뿐입니다.

## 4. 추천과 함께 보면 좋은 화면

추천 20세트와 **같은 통계 축**을 따로 볼 수 있는 화면입니다.  
세트를 직접 만들지는 않고, **왜 그런 순위가 나왔는지**를 확인하는 용도입니다.

### 조합 분석 (`/combination`)

- 최근 **3년(156회)** 기준으로, 1구~6구 각각에 **어떤 번호대가 자주 나왔는지** 순위를 보여 줍니다.  
- 추천의 **RANK11~20**이 쓰는 자리대 규칙과 **같은 표본**입니다.  
- 주번호 6개 합산의 고·저 극단 통계도 함께 볼 수 있습니다(추천 생성의 합계 제한과는 별개).

### 번호별 간격 (`/interval`)

- 1~45번이 **다시 나올 때까지의 간격**(평균·최대 등)을 표로 보여 줍니다.  
- 추천의 **RANK1~10**과 비슷한 “간격” 축이지만, 이 화면은 **본번호만** 집계하고 **평균·최대 표** 중심입니다.  
- 추천 RANK1~10은 **보너스 포함 + 최대 간격 근접/초과** 순위로 세트를 만듭니다.  
- 연속 출현은 한 묶음으로 보고 묶음 끝에서 다음 출현까지의 간격만 셉니다.

### 추천 화면과의 차이

| 구분 | 하는 일 |
|:---|:---|
| **추천** | 위 통계로 **20세트**를 만들고 저장 |
| **조합 분석** | 자리대·합산 통계만 **조회** |
| **번호별 간격** | 번호별 간격 통계만 **조회** |

같은 이력·같은 3년(또는 전체) 데이터를 바탕으로 해도,  
분석 화면의 표와 추천 20세트의 **역할은 다릅니다**.
