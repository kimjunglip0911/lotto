# 추천 번호 30세트가 만들어지는 흐름

> 이 문서는 **개발 내부 로직**이 아니라, 사이트를 사용하는 입장에서  
> **"버튼 한 번 누르면 왜 그 30세트가 나오는가?"** 를 설명합니다.

---

## 2. 30세트는 "이렇게" 만들어집니다

추천 번호 30세트는 **마구잡이 무작위가 아닙니다.**  
**1부터 45에서 제외 번호를 뺀 풀**로, **1부터 20세트를 먼저 고정**한 뒤 leftover 10세트를 붙입니다.  
제외 = **직전 회차 당첨(본6+보너스)** ∪ **기준 직전 최근 6회에서 보너스 포함 2회 이상 나온 번호**(중복은 한 번).

### 공통 전제

| 항목 | 현재 동작 |
|:---|:---|
| **번호 풀** | 1~45에서 위 제외 집합을 뺀 풀 (균등 분석「제외 번호」과 동일 규칙) |
| **통계 표본** | 자리대·미추첨 간격 모두 **DB 전체** |
| **홀짝 비율** | 쓰지 않음 |
| **합계 구간** | 쓰지 않음 |
| **번호 사용 횟수 한도** | 원래 “30세트에서 같은 번호 최대 3회” 규칙이 있으나, **지금은 잠시 꺼 둔 상태** |
| **과거 당첨 조합** | 기준 회차 **이전**에 실제로 나온 **본번호 6개**와 같으면 후보에서 뺌 (보너스 제외) |

### 1그룹 — RANK1~10 (미추첨 간격 추출)

각 번호가 **과거 최장 공백(최대 간격)에 얼마나 가까운지**를 봅니다.  
출현은 **본번호 6개 + 보너스 1개**를 모두 셉니다(같은 회차에 겹치면 한 번만).

1. 기준 회차 직전까지, 번호마다 끝난 출현 사이 간격과 **현재 미추첨 기간**을 구합니다.  
2. **최대**는 둘 중 큰 값입니다. 현재가 더 길면 최대를 그 값으로 갱신하므로, 현재가 최대를 넘는 경우는 없습니다.  
3. `|현재 − 최대|` 이 **작을수록** 순위가 높습니다. 거리가 같으면 미추첨 기간이 긴 번호가 위입니다.  
4. 창 안에서 한 번도 안 나온 번호는 **맨 아래**입니다.  
5. 그 순위로 1등~45등까지 매긴 뒤, **RANK1~5**는 1등부터 6칸씩 이어 갑니다. 제외 번호면 **다음 등수**로 건너뜁니다.  
6. **RANK6~10**은 다시 **1등부터** 훑되, 세트마다 번호대 개수를 맞춥니다. **6~10세트 안에서는 같은 번호를 쓰지 않습니다**(5×6=30개). 번호대가 모자라면 **남은 번호 중 가장 높은 등수**로 채웁니다.

| 세트 | 쓰는 간격 순위 칸(제외 없을 때) |
|:---|:---|
| RANK1 | 1~6등 |
| RANK2 | 7~12등 |
| … | … |
| RANK5 | 25~30등 |

| 세트 | 1번대 | 10번대 | 20번대 | 30번대 | 40번대 |
|:---|:---:|:---:|:---:|:---:|:---:|
| RANK6 | 1 | 1 | 2 | 1 | 1 |
| RANK7 | 1 | 1 | 1 | 2 | 1 |
| RANK8 | 1 | 2 | 2 | 1 | 0 |
| RANK9 | 0 | 2 | 2 | 2 | 0 |
| RANK10 | 1 | 0 | 3 | 1 | 1 |

번호대는 1~9 / 10~19 / 20~29 / 30~39 / 40~45입니다.

### 2그룹 — RANK11~17 (항목별 순위 로직)

과거 당첨번호 6자리를 **번호대(1~45, 1개 단위)** 로 보고,  
전체 이력에서 **자리마다 자주 나온 번호대**를 순위로 매깁니다.

| 세트 | 자리대 시작 순위 |
|:---|:---|
| RANK11 | 구간 1등 band |
| … | … |
| RANK17 | 구간 7등 band |

- 1번 자리(1구)부터 6번 자리(6구)까지 **순서대로** 번호를 고릅니다.  
- 목표 번호대가 이미 쓰였거나 후보가 없으면, **다음 등수 번호대**로 넘어갑니다(ladder).  
- 조합 분석 화면(`/combination`)과 **같은 전체 표본·자리대 규칙**을 씁니다.

### 3그룹 — RANK18~20 (균등 0회 · 3세트)

균등 분석 **최근 6회에서 0회**인 번호만 씁니다(제외 번호와 겹치지 않음).

| 세트 | 규칙 |
|:---|:---|
| RANK18 | **미추첨 간격**(0회 풀 안·1~6등 칸) |
| RANK19 | **항목별 순위**(구간 ladder, 0회 풀) |
| RANK20 | **항목별 순위**(구간 ladder, 0회 풀) |

0회 풀이 6개 미만이면 해당 슬롯은 비울 수 있습니다.

### 4그룹 — RANK21부터 30 (조합분석 미사용 등수)

RANK11부터 17이 조합분석 **1등~7등** 자리대를 쓰므로, leftover는 **안 쓴 높은 등수부터** 이어서 씁니다.

| 세트 | 자리대 시작 순위 |
|:---|:---|
| RANK21 | 구간 8등 band |
| … | … |
| RANK30 | 구간 17등 band |

1구부터 6구까지 순서대로 고르고, 목표 번호대가 없으면 다음 등수로 넘어갑니다. 자리대 조합이 안 되면 풀 조합으로 채웁니다.

### 슬롯을 채울 때 추가로 규칙

- 이미 만든 세트와 **6개 번호가 완전히 같으면** 쓰지 않습니다.  
- 겹치면 자리 하나를 골라 **번호 1개만** 바꿉니다(전체를 처음부터 다시 뽑지 않음).  
- 뒤쪽 슬롯(예: RANK19~20)이 안 만들어지면, **직전 세트를 되돌리고** 다른 조합으로 다시 시도합니다.  
- leftover는 **1부터 20세트를 채우고 복구한 뒤에만** 붙입니다. 뒤쪽 leftover가 비어도 앞 20세트를 되돌리지 않습니다.  
- leftover는 조합분석 **8등부터 17등** 자리대로 **30세트를 맞춥니다.**

## 3. 자주 묻는 점

- **왜 30세트인가요?**  
  1부터 20세트는 간격·자리대·균등 0회 관점이고, 21부터 30세트는 조합분석에서 안 쓴 8등부터 17등 자리대를 붙입니다.

- **회차를 바꾸면 세트도 바뀌나요?**  
  네. 회차마다 **그 시점까지의 당첨 이력**으로 간격·자리대를 다시 계산하기 때문에,  
  다른 회차를 고르면 30세트가 달라집니다.

- **무작위로 나오는 건가요?**  
  아닙니다. **간격 순위 → 자리대 순위 → leftover → 과거 당첨·중복 제외** 순으로 정해진 규칙입니다.  
  같은 회차·같은 이력에서는 **항상 같은 30세트**가 나옵니다(재현 가능).

- **제외 번호는 무엇을 빼나요?**  
  **직전 회차 당첨(본6+보너스)** 과, **기준 직전 최근 6회에서 보너스 포함 2회 이상** 나온 번호를 합친 집합입니다.  
  겹치면 한 번호로만 셉니다. 균등 분석 페이지 상단「제외 번호」와 같은 규칙입니다.  
  기준 회차보다 앞선 당첨이 없고 6회 창도 비면 제외 없이 1~45를 씁니다.

- **예전에 말하던 “채택 풀에서 번호 빼기”는 없나요?**  
  편차·누적 극값·연속 출현으로 후보를 줄이는 단계는 **쓰지 않습니다**.  
  지금 풀에서 빼는 것은 위 **제외 번호 집합**뿐입니다.

- **홀짝·합계 조건은요?**
  현재는 **홀짝 비율·고저 합산을 쓰지 않습니다**.

- **100% 당첨 보장인가요?**  
  아닙니다. 로또는 본질적으로 확률 게임이며, 이 사이트는  
  **"과거 통계상 간격·자리대 패턴"** 을 정리해 보여 줄 뿐입니다.

## 4. 추천과 함께 보면 좋은 화면

추천 30세트와 **같은 통계 축**을 따로 볼 수 있는 화면입니다.  
세트를 직접 만들지는 않고, **왜 그런 순위가 나왔는지**를 확인하는 용도입니다.

### 조합 분석 (`/combination`)

- **DB 전체** 기준으로, 1구~6구 각각에 **어떤 번호대가 자주 나왔는지** 순위를 보여 줍니다.  
- 추천의 **RANK11~20**이 쓰는 자리대 규칙과 **같은 표본**입니다.

### 미추첨 간격 (`/interval`)

- 1~45번이 **다시 나올 때까지의 현재 미추첨 기간**과 **최대**를 표로 보여 줍니다.  
- 추천의 **RANK1~10**과 **같은 축**입니다. 최신 회차 기준 **DB 전체**, **본번호+보너스**로 집계합니다.  
- 현재가 더 길면 **최대를 그 값으로 갱신**합니다. 순위는 **최대 근접**(같으면 미추첨 기간 긴 순, 미출현은 하단)입니다.  
- 연속 출현은 한 묶음으로 보고 묶음 끝에서 다음 출현까지의 간격만 셉니다.

### 추천 화면과의 차이

| 구분 | 하는 일 |
|:---|:---|
| **추천** | 위 통계로 **30세트**를 만들고 저장 |
| **조합 분석** | 자리대 통계만 **조회**(전체) |
| **미추첨 간격** | 미추첨 기간·최대 통계만 **조회**(전체) |

같은 이력 데이터를 바탕으로 해도,  
분석 화면의 표와 추천 30세트의 **역할은 다릅니다**. 홈(`/`)에서는 10세트씩 묶어 고르고, 번호 추천 화면은 전체를 보여 줍니다.
